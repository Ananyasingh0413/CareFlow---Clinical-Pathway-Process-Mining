\# CareFlow – Hospital Performance Analytics



\## Project Overview

CareFlow is a hospital process mining and data analytics project focused on analyzing patient journeys, identifying treatment delays, and understanding hospital operational performance.



\## Project Objectives

\- Analyze patient treatment journeys.

\- Identify delays in hospital activities.

\- Evaluate doctor availability and patient waiting time.

\- Discover process bottlenecks.

\- Visualize hospital performance through Power BI.



\## Data Processing

Python and Pandas are used for:

\- Data cleaning and transformation.

\- Missing value and duplicate checking.

\- Timestamp validation.

\- Calculating activity-wise time gaps.

\- Preparing datasets for analysis.



\## Process Mining

PM4Py is used for:

\- Event log analysis.

\- Directly-Follows Graph (DFG).

\- Process Tree discovery.

\- Patient pathway analysis.

\- Conformance checking.



\## Delay and Bottleneck Analysis

The project examines:

\- Doctor consultation waiting time.

\- Doctor availability and workload.

\- Laboratory and X-Ray delays.

\- Admission processing time.

\- Patient queue size.

\- Overall patient journey duration.



\## Power BI Dashboard

Power BI is being used to develop an interactive dashboard containing:

\- Patient journey analysis.

\- Admission and discharge statistics.

\- Activity-wise waiting time.

\- Doctor waiting time analysis.

\- Hospital bottleneck analysis.

\- Patient outcome distribution.



\## Tools and Technologies

\- Python

\- Pandas and NumPy

\- PM4Py

\- SQL

\- Power BI

\- Git and GitHub



\## Current Progress

Data preparation, validation, process discovery, patient delay analysis, doctor availability analysis, bottleneck identification, and conformance auditing have been developed.



Power BI dashboard development and visualization formatting are in progress.



\## Conclusion

CareFlow demonstrates how process mining and data analytics can help understand hospital workflows, identify operational delays, and highlight opportunities for improving patient flow and hospital efficiency.
